# 闲鱼客服本地化实践笔记

面向「闲鱼卖家自助客服」这类桌面工具的自研记录：**可复用模块 + 踩坑笔记**。

本仓库不含任何第三方程序的代码、资源或构建产物；所有内容均为原创实现或通用工程实践。

## 内容

| 路径 | 说明 |
|---|---|
| `modules/peer-filter.js` | **同行/推销话术识别**：把「代运营、互粉、刷单、加V、一件代发」这类非买家咨询挡在自动回复之外，转人工而不是硬答 |
| `docs/product-ai-knowledge.md` | **商品 AI 的知识闭环**：不训练模型也能越用越准——人工问答沉淀成 FAQ，本地检索优先命中 |
| `docs/mac-port-notes.md` | **Windows Electron 客户端 → macOS 移植实操**：asar、原生模块、签名、日志 |
| `docs/embedding-pitfalls.md` | **Electron 内嵌第三方页面的 4 个高频坑**：SameSite 丢 cookie、UA 泄漏、per-window session 污染、多开限流 |

## 为什么这些值得单独拿出来

- **同行识别**：闲鱼 IM 里混着买家咨询、同行推销、系统通知。只靠「消息来了就回」必然答错人。真正管用的是「身份闸门 + 话术过滤」两道。
- **知识闭环**：商用客服工具的「智能」大多不来自模型微调，而来自「答不上来 → 转人工 → 人工答案沉淀成 FAQ → 下次直接命中」。这条链路省钱且稳定。
- **移植笔记**：Electron 应用跨平台不是「重新编译」那么简单，原生模块、asar 的 unpacked 映射、adhoc 签名的 TCC 失效都是坑。
